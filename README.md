# USpeedo Email Plugins

USpeedo Email Plugin is a Dify plugin that enables developers to send emails through the USpeedo Email service directly inside workflows.

The plugin supports HTML email delivery, multiple recipients, flexible parameter configuration, and seamless integration with automated AI workflows.

Built on top of the USpeedo communication infrastructure, the plugin helps AI Agents and workflow systems trigger transactional emails, notifications, marketing campaigns, and automated communication scenarios with high reliability and global scalability，[Email Marketing ](https://uspeedo.com/en/email).

## Features

- Send HTML emails in Dify workflows
- Support for multiple recipients
- Flexible email parameter configuration
- Easy integration with AI Agents and automation systems
- Stable global email delivery infrastructure
- Developer-friendly API workflow support
